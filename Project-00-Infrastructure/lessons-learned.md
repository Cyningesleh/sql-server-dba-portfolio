# Lessons Learned – Project 00

## Key Takeaways

During the infrastructure deployment, I gained hands-on experience with:

- Creating and managing Hyper-V virtual machines.
- Configuring Windows Server 2019 as an Active Directory Domain Controller.
- Installing and configuring the DNS Server role.
- Implementing static IPv4 addressing.
- Joining Windows Server hosts to an Active Directory domain.
- Verifying DNS resolution using ping and nslookup.
- Creating SQL Server service accounts for future deployments.
- Documenting infrastructure using Markdown and GitHub.

## Challenges Encountered

- Configuring virtual networking in Hyper-V.
- Understanding the relationship between Active Directory and DNS.
- Organizing documentation and screenshots within GitHub.
- Learning enterprise-style documentation practices.
